# Number Adventure! 🎮

An educational web app for children to learn numbers 1-10, addition, and subtraction with audio and animations.

## Features

- 🎯 **Learn Numbers 1-10** - Click on numbers to hear them spoken aloud
- ➕ **Addition Practice** - Visual fruit counters with equations
- ➖ **Subtraction Practice** - Watch fruits disappear as you subtract
- 🌍 **9 Languages** - English, Spanish, German, French, Dutch, Portuguese, Italian, Japanese, Chinese
- 🔊 **Natural Audio** - Uses Edge TTS for clear, child-friendly voices
- ⭐ **Star Rewards** - Collect stars for correct answers
- 🎨 **Colorful Animations** - Engaging visual feedback

## Live Demo

🔗 **[Click here to try it!](https://nanapaknanapak-huemirit.github.io/learn-numbers-kids/)**

## How to Use

1. **Numbers Tab** - Click on any number (1-10) to hear it spoken
2. **Addition Tab** - Solve visual addition problems with fruit counters
3. **Subtraction Tab** - Watch fruits disappear as you subtract
4. **Language Selector** - Click on flag buttons to switch languages
5. **Score** - Collect stars by clicking numbers and solving problems

## Features in Detail

### Numbers Mode
- Click any number card to hear it spoken
- Fun facts about each number
- Star rewards for first click on each number
- "Play All" button to hear all numbers sequentially

### Addition Mode
- Random problems (numbers 1-5, sum ≤ 10)
- Visual fruit groups showing the problem
- Multiple choice answer buttons
- Celebration animations for correct answers

### Subtraction Mode
- Random problems (result ≥ 0)
- Fruits animate disappearing on correct answer
- Same visual and audio feedback as addition
